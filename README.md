# 心屿 · AI 情绪支持助手

网页 MVP，基于 Next.js。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:3000`。

## 当前实现范围

- 首页与线上咨询须知
- 移动端优先聊天界面
- 匿名本地会话
- 50 分钟倒计时与 10 分钟提醒
- 主题标签与优先主题选择
- OpenAI 真实模型优先的对话 API，本地原型兜底
- 非心理问题、乱答、危机风险的基础处理
- 结束咨询与总结生成
- 总结长图导出
- 历史总结页登录占位
- 隐私政策与服务条款基础页

## OpenAI 模型

在 `.env.local` 中配置：

```bash
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-4.1-mini
```

`/api/chat` 会优先调用 OpenAI Responses API。没有配置 API key 或模型请求失败时，会退回到本地原型回复，方便离线开发。

## 后续接入

当前 `/api/summaries/generate` 仍是可运行的原型实现。后续可按同样方式接入真实模型生成总结。

## 服务边界

心屿用于 AI 情绪支持与自我梳理，不替代真人心理咨询、心理治疗、精神科诊断或医疗服务。咨询总结仅供自我回顾，不作为诊断、评估或治疗依据。
